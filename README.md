# NORDIC MODULAR — Каталог модульных домов

Интерактивный веб-каталог модульных домов и бань с калькулятором дополнительных опций, сравнением проектов бок о бок, сметой в `localStorage` и переключением светлой/темной темы.

## Функциональность
- Фильтрация по категориям, живой поиск и сортировка (по цене и площади).
- Галерея экстерьера и интерьера в модальном окне.
- Интерактивный калькулятор опций с пересчетом стоимости в реальном времени.
- Сравнение до 3 проектов в сводной таблице.
- Боковая панель сметы с сохранением состояния в `localStorage`.
- Адаптивная верстка и переключение темы (`Light / Dark`) с учетом системных настроек.

## Стек
- HTML5, CSS3 (Grid, Flexbox, CSS Variables, Glassmorphism, анимации)
- Vanilla JavaScript (ES6+, `IntersectionObserver`, `localStorage`)
